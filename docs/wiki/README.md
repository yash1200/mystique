# Wiki source

These Markdown pages are the **in-repo wiki** for MystiqueDB. They are written to stay general and to mirror typical **GitLab Wiki** usage.

## Using with GitLab Wiki

You can:

1. **Copy** these pages into the GitLab project Wiki (Create page → paste content), or  
2. Keep this folder as the source of truth and link the Wiki home to the repository `docs/wiki/` tree, or  
3. If your team maintains a separate wiki git remote, sync from here when pages change.

Suggested GitLab Wiki page titles (match filenames without `.md`):

| File | Wiki page title |
| ---- | --------------- |
| `Home.md` | Home |
| `Product-Overview.md` | Product Overview |
| `Architecture.md` | Architecture |
| `Development.md` | Development |
| `FAQ.md` | FAQ |

Long specifications stay in `docs/*.md` (PRD, architecture, etc.). Wiki pages should **summarize and link**, not replace them.
